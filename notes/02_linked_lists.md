# Linked Lists
Functions almost similar to an array (list), with the principle benefit being that with linked lists, list elements can be inserted or removed without reallocation of any other elements.

A linked list is a linear collection of data elements called nodes that point to the next node by means of a pointer. 

Each node holds a single element of data and a link or pointer to the next node in the list. 

```bash

[ NODE(head) ] -> [ NODE ] -> [ NODE(tail) ] -> null
```
The data don't need to be stored in contigous blocks of memory and can exist in any memory address.

Linked lists are used to implement other data structures that include stacks, queues, graphs.

within linked lists, information can be accessed by navigating backward and forward
